Лабораторная работа №6
Цель работы
Изучить основы системы контроля версий Git и работу с удалёнными репозиториями GitHub.
Ход выполнения
1. Создан Fork исходного репозитория Kurtyanik/LR6.
2. Репозиторий склонирован на локальный компьютер с помощью GitHub Desktop.
3. Создан файл test.txt, добавлен текст и выполнен коммит.
4. Созданы ветки branch1 и branch2.
5. В каждой ветке внесены отдельные изменения в test.txt.
6. Выполнено слияние branch2 в branch1.
7. При слиянии возник конфликт. Он был разрешён вручную: в итоговом файле сохранены изменения из обеих веток.
8. Ветка branch2 удалена.
9. В ветке master создан файл notes.txt и выполнено несколько последовательных изменений с отдельными коммитами.
10. Выполнена отмена последнего коммита с помощью операции Revert.

В ходе лабораторной работы были изучены основные операции Git: создание веток, фиксация изменений, слияние веток, разрешение конфликтов и отмена коммитов. Также получены навыки работы с GitHub и GitHub Desktop.
